# Google to Bing Redirect (Chrome / Edge)

This extension redirects:
- google.com and www.google.com to Bing
- Google search pages to the matching Bing search URL, keeping the search query

## Install (Chrome or Edge)
1. Download this repository as a ZIP and unzip it.
2. Open chrome://extensions (or edge://extensions).
3. Turn on Developer mode.
4. Click Load unpacked.
5. Choose the unzipped folder.

The extension only redirects top-level visits to Google home/search pages. It does
not alter Google links, images, scripts, or other subdomains such as Gmail.

To remove it, open the extensions page and click Remove.
